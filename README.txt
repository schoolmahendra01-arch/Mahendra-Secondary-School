# श्री महेन्द्र माध्यमिक विद्यालय — Website

## खोल्ने तरिका
`index.html` लाई Chrome/Edge जस्ता browser मा खोल्नुहोस्।

## मुख्य फाइल
- index.html — वेबसाइटको content
- style.css — design/responsive layout
- script.js — mobile menu र year
- assets/ — विद्यालयको logo, building र principal photo

## पछि थप्न सकिने सुविधा
- सूचना व्यवस्थापन
- शिक्षक/कर्मचारी विवरण
- Admission form
- Result section
- PDF Downloads
- Online notice upload
- Google Maps
- Nepali/English language switch
- School administration dashboard
